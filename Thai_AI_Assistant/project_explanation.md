# 📘 คำอธิบายโปรเจกต์ Thai AI Assistant (สำหรับเสนอพี่เลี้ยง)

เอกสารนี้รวบรวมข้อมูลสำคัญทางเทคนิค เหตุผลในการเลือกใช้เครื่องมือ และหลักการทำงานของระบบ เพื่อใช้อธิบายที่มาที่ไปของโปรเจกต์ได้อย่างมั่นใจครับ

---

## 1. 🎯 ภาพรวมและแนวคิด (Concept)

**"สร้างผู้ช่วย AI ส่วนตัวที่เก่งภาษาไทย คุยด้วยเสียงได้ และทำงานบนเครื่อง Local เพื่อความเป็นส่วนตัว"**

เราต้องการระบบที่ผู้ใช้สามารถ **"พูดคุย"** กับ AI ได้เหมือนคุยกับคนจริงๆ (Natural Interaction) โดยไม่ต้องพึ่งหา API ราคาแพง และข้อมูลทั้งหมดประมวลผลอยู่บนคอมพิวเตอร์ของเราเอง (Local Execution) ทำให้ปลอดภัยและรวดเร็ว

---

## 2. 🛠️ Tech Stack & Tools (ทำไมถึงเลือกใช้อะไร?)

ระบบแบ่งเป็น 3 ส่วนหลัก คือ **Interface**, **AI Brain**, และ **Voice Processing**

### 🖥️ ส่วนติดต่อผู้ใช้ (Frontend & Application Logic)

- **เลือกใช้:** `Streamlit`
- **เหตุผล:**
  - พัฒนาได้รวดเร็วด้วย Python ภาษาเดียว ไม่ต้องเสียเวลาเขียน HTML/CSS/JS แยกกัน
  - มี Component สำหรับ Chat Interface และ Audio Player มาให้พร้อมใช้งานทันที
  - เหมาะที่สุดสำหรับการทำ Prototype หรือ App AI

### 🧠 สมองของ AI (LLM Engine)

- **เลือกใช้:** `Ollama`
- **เหตุผล:**
  - เป็นเครื่องมือที่รัน Large Language Models (LLM) บนเครื่องตัวเอง (Local) ได้ง่ายที่สุดในปัจจุบัน
  - จัดการเรื่องการดึง Model และการใช้ GPU ให้เราอัตโนมัติ (ไม่ต้อง config CUDA เองให้ยุ่งยาก)
  - มี REST API ให้ Python เรียกใช้งานได้ง่ายๆ

### 🗣️ ระบบเสียง (Voice Processing)

- **Speech-to-Text (ฟัง):** `Faster-Whisper`
  - **เหตุผล:** เร็วกว่า Whisper ดั้งเดิมของ OpenAI ถึง 4 เท่า และใช้หน่วยความจำน้อยกว่า ทำให้แปลงเสียงเป็นข้อความได้แบบ Real-time
- **Text-to-Speech (พูด):** `edge-tts`
  - **เหตุผล:** ให้เสียงภาษาไทยที่ธรรมชาติมาก (Voice: Premwadee/Niwat) เป็นเทคโนโลยีตัวเดียวกับใน Microsoft Edge ซึ่งใช้งานได้ฟรีและคุณภาพดีกว่า Library ทั่วไปมาก

## 3. 🤖 Model Selection (เลือก Model ตัวไหนมา และผลลัพธ์เป็นไง?)

เราเลือกใช้โมเดลแบบ **Open Source** เพื่อรันบน `Ollama`:

1.  **โมเดลหลัก (Hero Model):** `scb10x/llama3.1-typhoon2-8b-instruct` (Typhoon 2)
    - **ที่มา:** พัฒนาโดย SCB 10X (ทีม AI ของไทย)
    - **จุดเด่น:** สร้างจาก Llama 3.1 ของ Meta แต่เทรนเพิ่มด้วยข้อมูลภาษาไทยมหาศาล ทำให้เข้าใจบริบทไทย มุกตลก และวัฒนธรรมไทยได้ดีที่สุดในขนาดโมเดล 8B
    - **ผลลัพธ์:** ตอบคำถามภาษาไทยได้ไหลลื่น เป็นธรรมชาติ ไม่เหมือนหุ่นยนต์แปลภาษา

2.  **โมเดลทางเลือก:** `llama3`, `mistral`
    - เอาไว้เปรียบเทียบหรือใช้กับงานภาษาอังกฤษ

## 4. ⚙️ Code Structure & Logic (วิธีคิดและการเขียนโค้ด)

หลักการเขียนโค้ดเน้น **Modular Design** แยกหน้าที่ชัดเจน และใช้ **Session State** เพื่อจำบทสนทนา

### 🔄 กระบวนการทำงาน (The Flow)

ระบบทำงานเป็น Loop ตามแผนภาพนี้ครับ:

1.  **Input (รับค่า):**
    - รับเสียงจาก `mic_recorder` (คืนค่าเป็น Bytes) หรือรับข้อความจากช่อง Chat
2.  **Transcription (ถอดความ):**
    - ถ้าเป็นเสียง -> ส่งเข้าฟังก์ชัน `transcribe_audio()` ใช้ `Faster-Whisper` แปลงเป็นข้อความ
3.  **Processing (คิด):**
    - ส่งข้อความไปหา `query_ollama()`
    - ระบบจะส่งประวัติการคุยไปด้วย (Chat History) เพื่อให้ AI จำได้ว่าคุยอะไรกันอยู่
4.  **Generation (ตอบ):**
    - Ollama ส่งคำตอบกลับมาเป็น Text
5.  **Output (แสดงผล):**
    - แสดงข้อความใน Chat Box
    - ส่งข้อความไป `generate_audio()` ใช้ `edge-tts` เพื่อสร้างไฟล์เสียงแล้วเล่นทันที (`st.audio(autoplay=True)`)

### 💡 จุดเด่นในโค้ด (Highlight)

- **Caching (`@st.cache_resource`):** โหลด Model Whisper แค่ครั้งเดียวตอนเปิดโปรแกรม ไม่ต้องโหลดใหม่ทุกครั้งที่กดปุ่ม ช่วยให้โปรแกรมเร็วขึ้นมาก
- **Async Processing:** ใช้ `asyncio` กับ `edge-tts` เพื่อให้การสร้างเสียงไม่ไปบล็อกการทำงานของหน้าจอ (UI ไม่ค้างตอนรอเสียง)
- **Fallback Mechanism:** มีการเช็ค `try...except` เสมอ เช่น ถ้า Ollama ไม่ได้เปิดอยู่ โปรแกรมจะไม่พัง แต่จะแจ้งเตือนให้ไปเปิด

## 5. 🛠️ การตั้งค่าและใช้งาน (Setup & Usage)

สิ่งที่ต้องเตรียมก่อนรัน Demo ให้พี่เลี้ยงดู:

1.  **ติดตั้ง Ollama:** โหลดจาก [ollama.com](https://ollama.com)
2.  **ดึง Model:** เปิด Terminal พิมพ์:
    ```bash
    ollama pull llama3
    ollama pull scb10x/llama3.1-typhoon2-8b-instruct
    ```
    _(เช็คให้ชัวร์ว่า Model โหลดเสร็จแล้วด้วย `ollama list`)_
3.  **รันเซิร์ฟเวอร์:** เปิด Ollama ทิ้งไว้ (`ollama serve`)
4.  **รันโปรแกรม:**
    ```bash
    streamlit run app.py
    ```
