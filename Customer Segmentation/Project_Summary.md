# สรุปโครงการ Customer Segmentation ด้วย Local Models 🚀

เอกสารฉบับนี้สรุปกระบวนการและเทคโนโลยีที่ใช้ในการแบ่งกลุ่มลูกค้าจากความคิดเห็นบน YouTube โดยเน้นการใช้โมเดลที่รันบนเครื่อง Local ทั้งหมด เพื่อความเป็นส่วนตัวและประหยัดค่าใช้จ่าย

## 1. ภาพรวมกระบวนการ (Workflow Overview) 🔄

กระบวนการทำงานแบ่งออกเป็น 4 ขั้นตอนหลัก ดังนี้:

1.  **Data Collection (การเก็บรวบรวมข้อมูล)**: ดึงข้อมูลคอมเมนต์จากวิดีโอ YouTube
2.  **Data Processing & Embedding (การเตรียมข้อมูลและแปลงเป็นเวกเตอร์)**: แปลงข้อความให้เป็นรูปแบบตัวเลข (Vector) ที่คอมพิวเตอร์เข้าใจ
3.  **Clustering (การจัดกลุ่ม)**: ใช้ Math Model 3 รูปแบบเพื่อจัดกลุ่มคอมเมนต์ที่มีความคล้ายคลึงกัน
4.  **Insight Analysis (การวิเคราะห์เชิงลึก)**: ใช้ AI (LLM) อ่านคอมเมนต์ในแต่ละกลุ่มแล้วสรุปออกมาเป็น "Persona" ของลูกค้า

## 2. โมเดลและเทคโนโลยีที่ใช้ (Models & Technologies) 🛠️

### 2.1 การดึงข้อมูล (Scraping)

- **เครื่องมือ**: `youtube-comment-downloader`
- **หน้าที่**: ดึงข้อมูล Author และ Comment Text จากลิงก์วิดีโอที่กำหนด โดยไม่ต้องใช้ YouTube API (ซึ่งมีโควต้าจำกัด)

### 2.2 การแปลงเป็นเวกเตอร์ (Embedding)

- **โมเดล**: `sentence-transformers/all-MiniLM-L6-v2`
- **ประเภท**: Transformer-based Embedding Model
- **เหตุผลที่เลือก**:
  - เป็นโมเดล Open Source ขนาดเล็กแต่ประสิทธิภาพสูง
  - รันบน CPU ทั่วไปได้เร็วมาก (ไม่ต้องมีการ์ดจอแรงๆ)
  - แปลงประโยคเป็น Vector ขนาด 384 มิติ ซึ่งเพียงพอต่อการแยกแยะความหมาย

### 2.3 การจัดกลุ่ม (Clustering Models & Parameters) 🧮

เราได้ทดลองใช้ 3 โมเดลหลัก โดยมีการปรับตั้งค่า (Hyperparameters) อย่างละเอียดเพื่อให้ได้ผลลัพธ์ที่ดีที่สุด ดังนี้:

#### **A. K-Means Clustering (The Winner 🏆)**

- **Concept**: อัลกอริทึมที่แบ่งข้อมูลออกเป็น $K$ กลุ่ม โดยพยายามหา "จุดศูนย์กลาง" (Centroid) ของแต่ละกลุ่มที่ทำให้ผลรวมระยะห่างจากจุดข้อมูลทุกจุดไปยังจุดศูนย์กลางน้อยที่สุด
- **จุดเด่น**: ทำงานเร็ว เข้าใจง่าย เหมาะกับกลุ่มข้อมูลที่มีลักษณะเป็นกลุ่มก้อนกลมๆ (Spherical)
- **Parameters ที่ใช้**:
  - `n_clusters=5`: จำนวนกลุ่มที่เราต้องการแบ่ง (หาค่าที่เหมาะสมจาก Elbow Method)
  - `init='k-means++'`: เทคนิคการเลือกจุดศูนย์กลางเริ่มต้นแบบฉลาด (Smart Initialization) ที่กระจายตัวกันดีกว่าการสุ่ม ช่วยให้โมเดลลู่เข้าสู่คำตอบที่ดีได้เร็วขึ้น
  - `n_init=10`: รันโมเดลใหม่ 10 รอบด้วยจุดเริ่มต้นที่ต่างกัน แล้วเลือกผลลัพธ์ที่ดีที่สุด (ป้องกันกรณีสุ่มจุดเริ่มไม่ดี)
  - `max_iter=300`: จำนวนรอบสูงสุดในการขยับจุดศูนย์กลาง
  - `random_state=42`: ล็อกผลการสุ่มเพื่อให้ผลลัพธ์สามารถทำซ้ำได้ (Reproducibility)

#### **B. Agglomerative Clustering (Hierarchical)**

- **Concept**: การจัดกลุ่มแบบลำดับชั้น (Hierarchical) แบบ Bottom-up เริ่มต้นโดยมองว่า **"ทุกจุดคือ 1 กลุ่ม"** แล้วค่อยๆ จับคู่จุดที่ใกล้กันที่สุดรวมกันไปเรื่อยๆ เหมือนการสร้างแผนภูมิต้นไม้ จนกระทั่งเหลือจำนวนกลุ่มตามที่กำหนด
- **จุดเด่น**: ไม่ต้องกังวลเรื่องการสุ่มจุดเริ่มต้น และสามารถเห็นโครงสร้างความสัมพันธ์ย่อยๆ ของข้อมูลได้
- **Parameters ที่ใช้**:
  - `n_clusters=5`: จำนวนกลุ่มเป้าหมายที่จะตัดแบ่ง
  - `linkage='ward'`: เกณฑ์การรวมกลุ่ม โดยเลือกคู่ที่เมื่อรวมกันแล้วทำให้ **ความแปรปรวนภายในกลุ่ม (Variance)** เพิ่มขึ้นน้อยที่สุด (วิธีนี้มักจะได้กลุ่มที่มีขนาดใกล้เคียงกันและกระชับ)
  - `metric='euclidean'`: ใช้ระยะทางแบบยูคลิด (เส้นตรง) ในการวัดความห่าง

#### **C. Gaussian Mixture Models (GMM)**

- **Concept**: โมเดลทางสถิติที่มองว่าข้อมูลเกิดจากการผสมกันของ **"การกระจายตัวแบบระฆังคว่ำ" (Gaussian Distribution)** หลายๆ อัน
- **จุดเด่น**: ยืดหยุ่นกว่า K-Means มาก เพราะอนุญาตให้กลุ่มมีรูปร่างเป็นวงรีได้ (Elliptical) และบอกผลลัพธ์เป็น **ความน่าจะเป็น (Probability)** ว่าจุดหนึ่งๆ จะอยู่กลุ่มไหน (Soft Clustering)
- **Parameters ที่ใช้**:
  - `n_components=5`: จำนวนการกระจายตัว (กลุ่ม) ที่ใช้
  - `covariance_type='full'`: อนุญาตให้แต่ละกลุ่มมีรูปร่าง (Shape) และทิศทาง (Orientation) เป็นอิสระจากกันได้อย่างเต็มที่ (ยืดหยุ่นที่สุด)
  - `n_init=5`: รันซ้ำ 5 รอบเพื่อหาผลลัพธ์ที่ดีที่สุด เพราะอัลกอริทึม EM (Expectation-Maximization) ที่ใช้อาจติดกับดัก Local Optima ได้ง่าย
  - `random_state=42`: ล็อกผลการสุ่ม

**การวัดผล (Evaluation)**

- **Silhouette Score**: ใช้ค่านี้เป็นตัวตัดสิน (Benchmark) ว่าโมเดลไหนดีที่สุด ระบบจะเลือกผลลัพธ์จากโมเดลที่ได้คะแนนสูงสุดไปวิเคราะห์ต่อ

### 2.4 การวิเคราะห์ผล (Analysis)

- **โมเดล**: `Qwen/Qwen2.5-1.5B-Instruct` (หรือ `7B`) ผ่าน Library `transformers` และ `langchain`
- **ประเภท**: Large Language Model (Local LLM)
- **หน้าที่**: รับบทเป็น "Data Analyst" อ่านตัวอย่างคอมเมนต์ในแต่ละกลุ่ม แล้วสรุปออกมาเป็น:
  1.  ชื่อกลุ่ม (Naming)
  2.  นิสัย/ความชอบ (Behavior)
  3.  อารมณ์ (Sentiment)
- **เหตุผลที่เลือก**: โมเดลตระกูล Qwen 2.5 เป็น SOTA (State of the Art) ในรุ่นเล็ก ทำความเข้าใจภาษาไทยและอังกฤษได้ดีเยี่ยม กินทรัพยากรน้อย

## 3. เทคนิคการแสดงผลและหาค่า K ที่เหมาะสม (Visualization & Optimization) 📉

เพื่อให้เราเข้าใจผลลัพธ์ของการจัดกลุ่มได้ดียิ่งขึ้น เราใช้เทคนิคดังนี้:

### 3.1 การหาจำนวนกลุ่มที่เหมาะสม (Elbow Method) 💪

ก่อนที่เราจะเริ่มจัดกลุ่ม เราต้องตอบคำถามว่า "ควรแบ่งลูกค้าเป็นกี่กลุ่มดี?" (ค่า K เท่าไหร่?)

- **วิธีคิด**: เราจะลองแบ่งกลุ่มตั้งแต่ K=2 ไปจนถึง K=10 แล้ววัดค่า **Inertia** (ผลรวมระยะห่างจากจุดข้อมูลถึงจุดศูนย์กลางกลุ่ม)
- **การตีความกราฟ**:
  - เมื่อจำนวนกลุ่ม (K) เพิ่มขึ้น ค่า Inertia จะลดลงเสมอ (เพราะจุดอยู่ใกล้ศูนย์กลางมากขึ้น)
  - จุดที่เหมาะสมคือ **"จุดศอก" (Elbow Point)** ซึ่งเป็นจุดที่กราฟเริ่มหักเลี้ยวและมีความชันลดลงอย่างชัดเจน (แปลว่าการเพิ่มจำนวนกลุ่มหลังจากจุดนี้ ไม่ได้ช่วยให้ผลลัพธ์ดีขึ้นมากเท่ากับช่วงแรก)
  - ในโปรเจกต์นี้ เราพบว่าจุดศอกอยู่ที่ **K=5**

### 3.2 เทคนิคการแสดงผล (PCA vs t-SNE) 🎨

ข้อมูลของเราเป็น Vector ขนาด 384 มิติ (จาก Embedding) ซึ่งมนุษย์ไม่สามารถมองเห็นภาพใน 384 มิติได้ เราจึงต้อง "ลดมิติ" (Dimensionality Reduction) ลงเหลือ 2 มิติเพื่อพล็อตลงบนกราฟ 2D

#### **A. PCA (Principal Component Analysis)**

- **คืออะไร**: เทคนิคทางคณิตศาสตร์ที่พยายามหาแกนใหม่ (Principal Components) ที่เก็บความแปรปรวน (Variance) ของข้อมูลไว้ให้ได้มากที่สุด
- **จุดเด่น**:
  - **Global Structure**: รักษาโครงสร้างภาพรวมของข้อมูลได้ดี (รู้ว่ากลุ่มไหนอยู่ไกลกลุ่มไหน)
  - **Speed**: ทำงานเร็วมาก
- **ข้อจำกัด**: มักจะแยกกลุ่มที่ซ้อนทับกันซับซ้อนได้ไม่ดีเท่าไหร่ (ภาพอาจจะดูกองรวมกัน)

#### **B. t-SNE (t-Distributed Stochastic Neighbor Embedding)**

- **คืออะไร**: เทคนิคที่เน้นรักษาความสัมพันธ์ของจุดใกล้เคียง (Local Structure) โดยใช้ความน่าจะเป็น
- **จุดเด่น**:
  - **Cluster Separation**: แยกกลุ่มที่ซับซ้อนให้ออกขาดจากกันได้สวยงามและชัดเจนมาก เหมาะสำหรับการทำ Visualization โดยเฉพาะ
- **ข้อจำกัด**:
  - **Slow**: ใช้เวลาคำนวณนานกว่า PCA มาก
  - **No Global Meaning**: ระยะห่างระหว่างกลุ่มที่อยู่ไกลกันอาจจะไม่มีความหมายทางคณิตศาสตร์เท่า PCA (เน้นแค่ว่า กลุ่มเดียวกันต้องอยู่ด้วยกัน)

**สรุปการเลือกใช้**: เราใช้ **t-SNE** ในขั้นตอนสุดท้ายเพื่อแสดงภาพผลลัพธ์ที่สวยงามและชัดเจนที่สุด

## 4. สิ่งที่ได้เรียนรู้ (Key Takeaways) 💡

- การทำ **Unsupervised Learning** (Clustering) ช่วยให้เราเห็น Pattern ของลูกค้าโดยที่เราไม่ต้องกำหนด Label ล่วงหน้า
- การใช้ **Multiple Clustering Models** (K-Means vs GMM vs Agglomerative) ช่วยให้เราเห็นมุมมองของข้อมูลที่หลากหลาย และเลือกวิธีที่เหมาะสมที่สุดได้
- การใช้ **Local Models** ช่วยลดความเสี่ยงเรื่องข้อมูลรั่วไหล และไม่ต้องกังวลเรื่องค่าใช้จ่าย API
- การใช้ **Hybrid Approach** (Math Model จัดกลุ่ม + LLM สรุปผล) ช่วยให้เราได้ทั้งความแม่นยำทางคณิตศาสตร์ และความเข้าใจภาษามนุษย์ที่อ่านง่าย
